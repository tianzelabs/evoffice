# Gamification protocol

Gamification is the measurement and intervention layer shared by the two research
cases. It turns a persistent agent system into an observable longitudinal study;
it is not a claim that XP or leaderboards create intelligence.

## Mechanics

- public chat records claims, disagreement, uncertainty, and delegation;
- XP rewards validated improvement, not raw activity or luck;
- seasons create comparable observation windows;
- badges mark milestones without replacing the underlying record;
- the leaderboard compares versions and outcomes, not only employees;
- the append-only event ledger preserves actor, evidence, budget, and result.

## Incentive experiments

Run matched conditions with:

- no visible score;
- P&L-only score;
- validated-improvement XP;
- XP plus public peer review;
- XP with an anti-gaming penalty for redundant or invalid experiments.

## Measures

Track valid experiments, duplicate rate, XP per validated improvement, rank
stability, premature stopping, risk-taking, reward hacking, evidence quality, and
whether useful practices survive a worker reset.

More activity is not automatically better. A condition that produces more tests
but less reliable knowledge is a negative result.

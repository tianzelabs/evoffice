# MiMo 与 Haiku：真实行情数学测试

日期：2026-10-12。这轮小样本中，Haiku 的完整交付、费用和速度更好；两者已完成的滤波和鲁棒仓位核心函数都通过独立数值检查。没有证据支持仅因这轮测试把交易员换成 MiMo，也不能据此判断两者的一般高阶数学能力。

真实数据上的结论同样明确：三套预先固定的模型，在验证集及隐藏留出集上的预测 MSE 都略差于“下一分钟收益预测为零”。鲁棒仓位模型选择不交易。这是本次模型、特征和短窗口的结果，并不证明市场不存在其他机会。

## 测了什么

两边收到相同的三道题和相同可见数据，独立作答，没有互看答案：

1. **部分可观测模型**：推导并实现 Kalman 滤波，区分状态方差与收益预测方差，讨论参数可识别性，检查真实数据预测。
2. **有成本的随机控制**：实现有限期 Bellman 动态规划，包含换仓成本、逐期风险惩罚、终点清仓及指定的近似平局规则。
3. **鲁棒决策**：推导均值不确定区间下的最坏情形最优仓位；用训练集 OLS 构造点态均值区间，区分它与新收益的预测区间。

这是数学推导、计算和研究流程测试。固定参数与简单特征用于检验正确性，没有搜索盈利规则、调参挑赢家或按收益筛选模型。它不包含开放数学猜想的证明，也不是一般智力排行榜。

完整题目及运行协议：[tasks.json](../../spikes/07-real-data-math/tasks.json)、[protocol.md](../../spikes/07-real-data-math/protocol.md)。

## 数据与隔离

数据来自办公室只读行情接口，Kraken Futures `PF_XBTUSD`，UTC 2026-10-05 20:23 至 2026-10-12 20:22，共 9,909 根一分钟 K 线。缺失 171 分钟，形成 141 个连续片段，没有补齐缺失分钟。

在调用模型之前，按时间将 K 线分为 60% 训练、20% 验证、20% 隐藏留出。跨分区或跨缺失分钟的标签对剔除。训练有效收益 5,933 个，训练相邻收益对 5,921 个；留出有效收益 1,963 个，相邻对 1,943 个。

模型只能通过独立、持久的 Python 工具看到训练和验证数据，可用 numpy/pandas/scipy。工具没有 API 密钥、网络、用户文件读取或下单能力；隐藏留出文件读取拒绝已实测。所有答案冻结后才进行离线留出核验。办公室单独的 60 天评估窗口没有访问。

训练期没有可用盘口价差和资金费率记录。没有借用后来的数据估计成本，也没有把缺失当成零。仅使用办公室快照中已知的 taker 单边 5 bps 手续费：控制题单边成本 5 bps，鲁棒题往返成本 10 bps。价差、资金费率、冲击和延迟等未计入，因此任何代理收益都不是可执行交易结果。

原始数据哈希、分区及成本缺失记录：[manifest.json](../../spikes/07-real-data-math/data/manifest.json)。

## 独立检查结果

| 任务 | Haiku 5.5 | MiMo V2.6 Pro |
|---|---|---|
| 滤波函数 | 16/16，完整交付 | 16/16，整理 JSON 后可核验 |
| 控制函数 | 20/20，完整交付 | 未完成；工具中的候选代码 17/20 |
| 鲁棒仓位函数 | 394/394，完整交付 | 394/394，整理 JSON 后可核验 |

滤波的独立参照使用联合高斯直接条件化，而不是重复同一滤波递推。控制使用独立动态规划及短时域的反馈策略递归枚举。鲁棒仓位检查直接目标函数最大值、密集网格、边界及零风险惩罚情形。

控制最初有 16 个用例；发现 MiMo 候选代码采用精确相等比较后，增加 4 个针对题目明确要求的 `1e-10` 近似平局用例。两者都运行了同一增补检查，没有给模型反馈或要求重答。MiMo 通过原 16 例，新增 4 例通过 1 例。此增补属于事后诊断，不伪称事前冻结，记录见 [checks-amendment.json](../../spikes/07-real-data-math/checks-amendment.json)。

通过函数用例不代表报告每一句话都正确。人工检查还发现：

- MiMo 滤波推导把稳态条件预测方差写成了无条件边际方差 `V+R`，并写 `K=V/(V+R)`。一般情形应解 Riccati 方程。本题正确稳态预测方差是 **22.08560188**，增益 **0.01615882**；边际方差是 **22.13898097**。其实际递推代码和实数结果正确，因此这一项是解释中的数学错误。
- Haiku 正确给出上述稳态数值，但把七天样本写成约 1.5 周。两者部分辅助自协方差诊断将不同连续片段拼接，主滤波与预测没有因此跨缺口泄漏。
- MiMo 鲁棒题的前言将约 2.8 倍标准差差异写成方差差异；方差比实际约 7.8。最终答案正确区分均值区间与收益预测区间，也说明用收益落入均值区间的次数不能验证真实均值的覆盖率。
- Haiku 鲁棒题结论写“无残差自相关”过宽；实际只检查了片段内的一阶线性相关，限制部分承认不能证明独立。成本文字写成 maker/taker 也不精确，实际使用的是两次 taker 手续费。

原始答案、工具日志、生成代码和逐项检查均保留：[verification.json](../../spikes/07-real-data-math/verification.json)。

## 真实数据结果

MSE 单位为 bps²。不同任务有效样本数不同，应分别与同一行的零预测基线比较。

| 固定模型 | 验证 MSE | 验证零基线 | 隐藏留出 MSE | 留出零基线 |
|---|---:|---:|---:|---:|
| Kalman 滤波 | 2.777774 | 2.763121 | 14.317088 | 14.315174 |
| 两状态条件均值 | 2.808836 | 2.803846 | 14.427536 | 14.425935 |
| OLS 条件均值 | 2.809930 | 2.803846 | 14.432377 | 14.425935 |

两者已完成的滤波和鲁棒代码复算结果一致，匹配独立参照。控制题的训练参数和策略表也一致：两个状态、各个时域都选择平仓/保持空仓。控制行的预测 MSE 是独立程序对冻结的训练条件均值进行评估，不代表 MiMo 完成了其验证报告。

鲁棒模型在验证 1,775 次机会和隐藏留出 1,943 次机会中均为零次交易。留出最大预测均值绝对值只有约 0.489 bps，远低于 10 bps 往返手续费代理阈值，均值不确定性进一步收紧交易条件。零代理收益来自不交易，不能称为盈利策略。

滤波验证集名义 95% 预测区间覆盖率达 99.95%，但训练波动明显高于验证波动；过宽区间不能当成预测能力。仅七天数据、一个短留出区间及预设简化模型，不能证明稳定收益或普遍无收益。

详细参照：[reference-summary.json](../../spikes/07-real-data-math/reference-summary.json)。

## 交付、延迟与费用

双方均开启推理，每题最多 4 次 API 请求，每次输出上限 32,768 tokens（包括推理），大于前轮的 6,000。这轮没有因输出上限截断的答案。

Haiku 三题全部直接交付有效 JSON，没有工具错误。MiMo 滤波答案缺一个外层闭括号，且两个字段放错层级；鲁棒答案有前言、JSON 代码围栏和 6 个非法的单引号转义。这些已单独记录格式修复，保留原文，未修正数学、数值或算法。严格的自动 JSON 交付仍算失败，不能把整理后的可评分答案冒充原本直接成功。

MiMo 控制题第三次工具执行将时间对齐条件写错，得到空数组并报错。第四轮本应提交最终答案，却输出了文字形式的工具调用；其中修复代码未执行。该题记录为未完成，只对先前实际生成的候选函数进行部分检查。

本轮**已知账单合计 0.06398407 美元**；另有该超时请求的实际费用未知，按请求上限预留 **0.03192639 美元**，保守预算记账合计 **0.09591046 美元**。预留不是已确认消费。记录见 [cost-summary.json](../../spikes/07-real-data-math/cost-summary.json)、[rescue-protocol.json](../../spikes/07-real-data-math/rescue-protocol.json)。
